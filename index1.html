About

PublicnEUro is a data repository for brain imaging data: MRI, PET, MEG, EEG, etc. The principle is similar to OpenNeuro, where each dataset is shared independently. Once shared, a DOI is available for citation, and the link allows users to access the data.

Open Access, Controlled Access and GDPR compliance

PublicnEUro host data enabling open and controlled access to share brain imaging data in a way that is as FAIR as possible. Each dataset receives a DOI and all metadata are open access. Because your data may need to be protected, we provide the necessary privacy protections by identifying users, recording transactions, and control access. PublicnEUro is designed to be compliant with the General Data Protection Regulation (GDPR) and other relevant regulations.
